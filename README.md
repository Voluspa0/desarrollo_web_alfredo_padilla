# Tarea 3 - Desarrollo Web
**Autor:** Alfredo Sebastián Padilla Loyola
   
## Descripción
En esta tarea se busca implementar la sección de Estadísticas, incluyendo gráficos construidos de acuerdo a la información presente en la base de datos. Además, se incorporan las herramientas para comentar las actividades y visualizarlas.
   
## Decisiones tomadas
   - Los archivos se organizaron en carpetas de acuerdo al lenguaje en el cual fueron programados y los nombres de estos archivos se condicen entre las diferentes ventanas.
   - Con el fin de clasificar los horarios de las actividades y generar el gráfico correspondiente por horario y mes, se definieron tres segmentos horarios: Mañana (00:00 a 11:59), Mediodía (12:00 a 15:00) y Tarde (15:01 a 23:59), de acuerdo ala hora de inicio de la actividad.
